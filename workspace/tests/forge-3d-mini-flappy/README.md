# FORGE 3D - Mini Flappy (Godot 4.4.1)

Small original 3D game: fly the bird through moving 3D gates. Real physics (RigidBody3D + collision shapes),
perspective follow camera, procedural meshes/materials/sounds (no external assets), HUD, game over and retry.
Input: keyboard (Space/Up), mouse click, touch. GL Compatibility renderer, Web preset ready.
Run the demo bot with: `godot --path . -- --bot`
