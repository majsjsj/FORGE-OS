# FORGE Studios

Run `uv run forge scaffold <studio> <directory>` to create a starter project without overwriting existing files.

| Studio | Starter output | Current capability |
|---|---|---|
| web | HTML, CSS, JS | Static web starter |
| android | Gradle app and Java Activity | Native Android starter; build requires Android SDK/Gradle |
| game | Canvas HTML and JS | Browser game loop starter |
| saas | FastAPI service skeleton | API skeleton only; no production auth/billing/database |
| api | FastAPI health endpoint | API skeleton |

These are starter templates, not finished products or production-ready builds. Build/test adapters, emulator automation, engine-specific Unity/Godot integration, and release packaging remain future work.
