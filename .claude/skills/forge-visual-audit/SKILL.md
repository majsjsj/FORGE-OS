# FORGE Visual Audit

Record visible layout, hierarchy, text, colors, spacing, typography, borders, shadows, and icons. Separate observations from estimates. Inspect the project and implement in its established framework. Capture a rendered screenshot only when an approved browser tool is available. Compare by geometry, typography, color, assets, and responsive behavior; fix high-impact mismatches and repeat. Never claim pixel-perfect similarity without a real reference and rendered output.
