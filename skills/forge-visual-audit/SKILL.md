# FORGE Visual Audit

1. Record visible layout, hierarchy, text, colors, spacing, typography, borders, shadows, and icons.
2. Separate observations from estimates; do not invent hidden behavior or assets.
3. Create a component inventory and responsive assumptions.
4. Inspect the existing project and implement in its established framework.
5. Capture a rendered screenshot only if an approved browser tool is available.
6. Compare output by geometry, typography, color, assets, and responsive behavior.
7. Fix high-impact mismatches and repeat the comparison.

Do not claim pixel-perfect similarity without an actual reference and rendered output.
